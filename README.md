# AegisShield BookEasy Pilot

Simulated portfolio case study by Eva Marquez.

This case shows how I would coordinate a controlled modernization project for a fictional cybersecurity SaaS product. BookEasy is the fictional customer used for the pilot.

## Methodology

This project uses a hybrid approach:

- A planned approach for scope, risks, approvals, dates, and release decisions.
- Small delivery and test steps for the technical work, so the team can find and fix issues before moving forward.

In plain words: agree on the direction first, then build, test, and improve the work in stages.

## What the case shows

- Project framing and sponsor handoff.
- Charter, scope, roles, risks, and communication.
- Technical requirements, delivery plan, WBS, RACI, backlog, and schedule.
- Testing, migration, rollback, issue handling, and status reporting.
- GitHub Projects board states from planning through close-out.
- Pilot acceptance, release approval, operations handover, and lessons learned.
