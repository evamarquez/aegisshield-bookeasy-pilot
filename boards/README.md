# GitHub Projects board states

These files explain what each board snapshot shows. The screenshots are labeled as simulated states because the project is fictional.

| State | What it shows |
|---|---|
| Week 2 | Scope, owners, dates, and first work ready to start |
| Week 8 | ISS-01 found during testing; pilot blocked |
| Week 9 | Fix in progress; schedule change waiting for approval |
| Week 10 | Fix retested and closed; pilot ready |
| Week 13 | Release stabilized; operations handover complete |

## Board columns

Pending, In progress, In review, In testing, Blocked, and Done.

Each card represents a work item from the backlog or a project issue. The real project board is connected to the repository on GitHub.
