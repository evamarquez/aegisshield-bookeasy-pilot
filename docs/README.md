# Case 01 — Cybersecurity Platform Modernization

## Methodology

This case uses a hybrid approach. The plan sets the scope, risks, approvals, dates, and release decisions. The technical work is delivered in small steps so it can be built, tested, and corrected before the next step.

The live GitHub evidence is in the separate [AegisShield BookEasy Pilot repository](https://github.com/evamarquez/aegisshield-bookeasy-pilot), with boards for week 2, week 8, and week 13.

> Simulated portfolio case study. This is a fictional project created for learning and portfolio demonstration; it is not presented as professional client experience.

## Case overview

**Company:** AegisShield (fictional cybersecurity SaaS company)  
**Product:** Aegis Security Cloud (fictional integrated security platform)  
**Primary role:** Junior Technical Project Manager  
**Supporting perspectives:** Business Analyst and Product Manager  
**Project:** Aegis Security Cloud Modernization - BookEasy Pilot  
**Project type:** Controlled modernization increment for an existing cybersecurity platform

AegisShield has not completed a major platform modernization in approximately five years. The company needs to understand its technical debt, reduce operational and security risk, and create a realistic delivery plan without disrupting current customers.

## What this case is designed to demonstrate

- Current-state analysis of a technical product.
- Translation of business and security risks into a project scope.
- Coordination across engineering, QA, DevOps, security, support, and product.
- Dependency, risk, communication, and release planning.
- Evidence-based prioritization instead of treating every upgrade as equally urgent.
